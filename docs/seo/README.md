# SEO Documentation

This folder contains all SEO-related documentation and templates for the website.

## Files

### 📋 Templates & Guides
- **`seo-metadata-template.csv`** - CSV template for preparing SEO metadata for all tools
- **`SEO_METADATA_TEMPLATE.md`** - Detailed template format and guidelines
- **`SEO_UPDATE_GUIDE.md`** - Step-by-step guide for updating SEO metadata

### 📚 Reference Documents
- **`tool-slugs-reference.md`** - Complete mapping of all tool slugs, URLs, and OG image paths
- **`STANDARDIZATION_COMPLETE.md`** - Summary of URL and canonical standardization work

## Quick Start

1. **To prepare SEO metadata:**
   - Use `seo-metadata-template.csv` as a starting point
   - Follow guidelines in `SEO_METADATA_TEMPLATE.md`
   - Refer to `SEO_UPDATE_GUIDE.md` for detailed instructions

2. **To reference tool information:**
   - Check `tool-slugs-reference.md` for tool slugs, URLs, and naming conventions

3. **To understand what was standardized:**
   - See `STANDARDIZATION_COMPLETE.md` for the complete list of changes

## Standard Naming Conventions

- **Canonical URL**: `/tools/{tool-slug}` (lowercase, hyphens)
- **OG Image Path**: `/tools/{tool-slug}-og.jpg`
- **OG Image Location**: `public/tools/{tool-slug}-og.jpg`
